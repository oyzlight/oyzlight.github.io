USB 虚拟串口 (CDC ACM)

USB 虚拟串口（Virtual COM Port）通过 USB CDC ACM（Communication Device Class, Abstract Control Model）协议，将 USB 设备模拟成一个标准串口，使得上位机可以通过串口终端访问 USB 设备，无需额外驱动。

注意事项

  1. 中断安全：读写指针的修改需考虑中断上下文，使用 volatile 修饰
  2. 打印重定向：将 printf 重定向到 CDC 后，注意不要在中断中大量打印，会阻塞主循环
  3. USB 连接状态：发送前应检查 USB 是否已连接（hUsbDeviceFS.dev_state == USBD_STATE_CONFIGURED）
  4. 速度限制：USB FS（全速）理论带宽 12Mbps，CDC 实际吞吐量约 1-2 Mbps
  5. 流控：如果上位机读取速度低于 MCU 发送速度，缓冲区会溢出，需做好丢弃策略
