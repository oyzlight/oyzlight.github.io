FDCAN 通信

概述

FDCAN（CAN with Flexible Data-Rate）是经典 CAN 2.0 的升级协议，由 Bosch 于 2012 年发布。它在保持 CAN 总线物理层和仲裁机制不变的前提下，通过引入可变速率和数据场扩容，将有效带宽提升了数倍乃至数十倍。

经典 CAN 最高只能到 1 Mbps，单帧最多传输 8 字节数据，在传输固件升级包、传感器原始数据等场景下捉襟见肘。FDCAN 正是为了解决这个瓶颈而设计的。

FDCAN 与经典 CAN 的核心区别

特性 经典 CAN (2.0) FDCAN
最大速率 1 Mbps 仲裁段最高 1 Mbps，数据段最高 8 Mbps 或更高
单帧数据量 0-8 字节 0-64 字节
CRC 长度 15 bit 17 bit (≤16 bytes) / 21 bit (>16 bytes)
帧类型 标准帧、扩展帧 增加 FDCAN 帧（FD帧）、BRS 帧
兼容性 — 向下兼容经典 CAN 2.0
协议 CAN 2.0A/B ISO 11898-1:2015 (CAN FD)
位速率切换 不支持 支持 BRS（Bit Rate Switch），数据段可加速

关键点：FDCAN 控制器可以收发经典 CAN 帧，但经典 CAN 控制器无法识别 FDCAN 帧。在实际系统中混用时需要注意这一点。

FDCAN 数据帧格式

FDCAN 数据帧在经典 CAN 帧的基础上新增了若干控制位：

字段 长度 说明
SOF 1 bit 帧起始，显性电平
ID 11 bit / 29 bit 标识符，仲裁段以标准速率发送
RRS 1 bit 远程请求替代位（FDCAN 不再支持远程帧）
IDE 1 bit 标准帧/扩展帧标志
FDF 1 bit FDCAN 帧标志，隐性表示该帧为 FDCAN 帧
res 1 bit 保留位
BRS 1 bit 位速率切换位，隐性表示数据段切换到高速
ESI 1 bit 错误状态指示
DLC 4 bit 数据长度编码，0-8/12/16/20/24/32/48/64
Data 0-64 bytes 数据域（在 BRS=1 时以高速传输）
Stuff Count 4 bit 填充位计数（FDCAN 新增）
CRC 17/21 bit 增强 CRC，含 Stuff Count
CRC Delim 1 bit CRC 界定符
ACK 2 bit 应答
EOF 7 bit 帧结束

DLC 编码对照表

DLC 值 数据字节数
0-8 0-8 bytes
9 12 bytes
10 16 bytes
11 20 bytes
12 24 bytes
13 32 bytes
14 48 bytes
15 64 bytes

三种帧类型

FDCAN 控制器可以发送和接收三种帧：

  1. 经典 CAN 帧：FDF=0，完全兼容传统 CAN 2.0，速率固定，数据 ≤ 8 字节
  2. FDCAN 帧（无变速）：FDF=1, BRS=0，使用 FDCAN 帧格式，最多 64 字节，但全程同速
  3. FDCAN 帧（变速）：FDF=1, BRS=1，数据段以更高位速率传输，是最常用的 FDCAN 模式

滤波器配置

FDCAN 的滤波器与经典 STM32 CAN 有较大不同。经典 bxCAN 使用共享的 14 个滤波器组，而 FDCAN（基于 M_CAN IP）的滤波器分为两类：

标准滤波器（Standard Filter）

用于在 Rx FIFO 0/1 间分配消息，最多 128 个。每个滤波器可以配置为：

  • Range 模式：匹配一个 ID 范围 [FilterID1, FilterID2]
  • Dual ID 模式：精确匹配两个 ID（FilterID1 或 FilterID2）
  • Classic 模式：等同经典 CAN 的掩码模式（FilterID + FilterMask）

扩展滤波器（Extended Filter）

在标准滤波器之前执行，决定消息进入哪个 Rx Buffer，不需要同时支持标准和扩展帧时不需配置。

FDCAN 与经典 CAN 共存

实际项目中常需要 FDCAN 和经典 CAN 共存：

  1. 物理层完全相同：同一个收发器（如 TJA1043）可同时支持 CAN 和 CAN FD
  2. 帧级别区分：FDF 位隐性（1）表示 FDCAN 帧，显性（0）表示经典帧——这是自动区分的
  3. 向下兼容：FDCAN 节点可以发送和正确接收经典 CAN 帧
  4. 速率限制：经典 CAN 节点在数据段加速期间会报错，因此变速 FDCAN 帧只能发给 FDCAN 节点

实际使用注意事项

  1. 收发器选型：经典 TJA1050 最高支持 1M，FDCAN 需要 TJA1043 或 MCP2558FD 等支持高速的收发器
  2. 终端电阻：FDCAN 对信号完整性要求更高，务必在总线两端正确焊接 120Ω 终端电阻
  3. Message RAM 分配：FDCAN 的 RAM 需要手动分配各区域大小（TxFIFO/Q, TxBuffer, RxFIFO, RxBuffer 等），配置不当会导致初始化失败
  4. 时钟源：FDCAN 外设需要独立的位时钟源（通常是 PLLQ 或 HSE），配置波特率前先确认时钟路径
  5. BRS 位：仅在 FDF=1 时 BRS 才有效，发送经典 CAN 帧时 BRS 被忽略
  6. TDC（Transmitter Delay Compensation）：数据段速率超过 2M 时需要使能 TDC 来补偿发送延迟，否则远端节点可能解码失败。在 CubeMX 中勾选 TDC 即可
